# Дневник

Простое учебное Android-приложение на Kotlin. Обычные Activity и XML, без Compose.

Вход: **student / 123456**. После входа показываются ученик, класс и таблица из девяти предметов с оценками и фамилиями преподавателей. Есть кнопка выхода. Вход сохраняется до выхода.

## База данных

SQLite находится внутри приложения, интернет и сервер не нужны. При первом запуске создаются таблицы students и subjects и заполняются примерами. Вход проверяется запросом к БД, предметы выбираются по ID ученика.

Данные можно поменять в DatabaseHelper.kt. Чтобы новые примеры появились на уже установленном приложении, очистите его данные или переустановите приложение.

Это учебный пример с одним аккаунтом и паролем в открытом виде в локальной базе. Для настоящего школьного дневника потребуется сервер с отдельной авторизацией.

## Android Studio

1. Скачайте исходники и откройте папку, где лежит settings.gradle.kts.
2. Выберите Gradle JDK 17 и дождитесь синхронизации. Нужен Android SDK 35.
3. Нажмите Run для запуска на телефоне/эмуляторе или Build APK(s) для APK.

Windows: gradlew.bat assembleDebug. Linux/macOS: ./gradlew assembleDebug.

APK: app/build/outputs/apk/debug/app-debug.apk. Минимальная версия телефона — Android 5.0.

Git для локальной сборки не нужен. Можно удалить .git, .github и .gitignore. **Оставьте gradle, gradlew и gradlew.bat: это файлы сборки, а не Git.**

## GitHub Actions и релиз

Push в main запускает сборку и lint. Тег v* дополнительно запускает проверки на Android-эмуляторе и публикует APK в Releases после успешных проверок. Ручной запуск собирает APK без создания релиза.

Релиз подписывается постоянным ключом из GitHub Secrets: DIARY_KEYSTORE_BASE64, DIARY_STORE_PASSWORD, DIARY_KEY_PASSWORD, alias diary. Ключ и пароли в репозиторий не попадают.

Для резервной копии ключа используйте ручной workflow Signing backup: он создаёт ZIP с ключом и паролями как закрытый Actions artifact на один день. Скачайте его из своего аккаунта и храните отдельно.

Без переменных локальная release-сборка использует отладочный ключ. Для обновления поверх опубликованного APK нужно использовать тот же постоянный ключ.

Для локального подписанного релиза задайте переменные DIARY_KEYSTORE (полный путь к .jks), DIARY_STORE_PASSWORD, DIARY_KEY_PASSWORD, затем запустите gradlew.bat assembleRelease.

Документация SQLite: https://developer.android.com/training/data-storage/sqlite
